# Corbin's Cram Arcade — ELA

In-progress companion to [cram-arcade](https://github.com/J4m3sdev/cram-arcade), focused on Corbin's Lang Arts finals (Literary Terms, Much Ado About Nothing, Robinson Crusoe, Lord of the Flies).

Right now `index.html` is a minimal placeholder that defines the `TERMS` array (6 topics, 76 entries). The arcade game shell (Flash Cards, Speed Quiz, Match Up, Type It, Survival, Target Range, Blitz, Memory, Final Boss) will be ported from the original repo in a follow-up.

Live: https://j4m3sdev.github.io/corbins-cram-arcade/ (once Pages finishes its first build)
